7. AI Features
7.1 At-Risk Student Prediction
A Random Forest Classifier is trained at server startup on student data from the database. It predicts a risk
score (0–100%) for every student and uses SHAP to explain the top 3 contributing factors in plain English.
Input Features Model Output
avg_marks_pct
fee_defaults
failing_subjects
grade_trend
Random Forest
Classifier
(scikit-learn)
+ SHAP
Risk Score 0–100%
n High  >70%
n Medium 40–70%
n Low   <40%
+ Top 3 reasons
Example Output: n Ahmed Khan — Risk: 84% | "Avg marks dropped from 72% to 51%" | "Failing 3 subjects" |
"2 unpaid invoices"
7.2 RAG Policy Chatbot
RAG (Retrieval-Augmented Generation) — the chatbot searches school policy documents first, then answers
using only what it found. It will say "I don't know" if the answer is not in the documents. This prevents
hallucination.
